# Design direction

SPK Penjadwalan Perkuliahan is an academic operations workspace for Teknik Elektro, Universitas Mataram. Its visual language takes cues from the supplied CoolAdmin template: bright neutral work surfaces, a restrained blue accent, compact clear navigation, and crisp separation between data regions. Use the existing Plus Jakarta Sans for readable Indonesian UI and retain the university's existing mark.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1.

Design decisions: the dark navy sidebar anchors navigation and recalls CoolAdmin's admin shell; blue marks the current route and primary action so users can locate where to work; pale neutral backgrounds keep dense schedules readable; the dashboard puts academic period and schedule status before secondary counts because that is the first operational context admins need; motion stays to short hover and focus transitions to keep the interface calm.
